## Setup and Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd PlanSpatial-AI
```

### 2. Install dependencies

Install the dependencies using the package manager required by the project.

For a Node.js project:

```bash
npm install
```

For a Python project:

```bash
pip install -r requirements.txt
```

### 3. Environment Configuration

Create a `.env` file and add the required environment variables.

```env
API_KEY=your_api_key_here
```

Do not upload your actual API keys, passwords or secrets to GitHub.

### 4. Run the Application

Use the appropriate development command configured in the project.

For example:

```bash
npm run dev
```

## Design Choices

The project focuses on combining AI capabilities with a simple and accessible interface.

The main design considerations include:

- **User Experience:** Keeping the interface simple and easy to navigate.
- **Modular Design:** Separating application components for easier maintenance.
- **AI Integration:** Using the selected AI technology to support floor plan intelligence.
- **Scalability:** Designing the application so that additional features can be introduced.
- **Maintainability:** Organizing the code to make future updates easier.

## Limitations

- Performance depends on the quality of the input data.
- AI-generated results may require manual verification.
- Complex floor plans may present challenges.
- Results depend on the capabilities of the integrated AI model.
- The application may have limitations based on supported file formats and available resources.
